# Amicor Ecosystem Overview

Amicor XS is the ecosystem platform layer. Amicor Health ISF is the first operational module focused on healthcare transportation coordination and rural behavioral health access.

## Purpose

This structure defines a startup-ready architecture for planning, building, and scaling:

- Operational healthcare transportation workflows
- Vetted independent contractor driver network operations
- Partner and provider coordination
- Modular ecosystem growth across future service lines

## Design Principles

- Modular by default: each domain can evolve independently
- MVP-first delivery: define only what is needed to launch safely
- Documentation-driven execution: workflows and ownership are explicit
- Compliance-aware architecture: healthcare context, privacy, and auditability
- Future-ready foundation: AI and automation can plug in without rework

## Core Modules

- `amicor-xs-core`: platform-level standards and shared capabilities
- `amicor-health-isf`: operational healthcare transportation module
- `mvp-build`: milestone planning and phased build execution
- `driver-network`: independent driver lifecycle and standards
- `partner-portal`: partner/provider interaction model
- `admin-dashboard`: operations and governance control center
- `notifications-system`: communications orchestration layer
- `scheduling-system`: request-to-assignment orchestration layer
- `api-structure`: domain API boundaries and contracts
- `future-ai-modules`: AI, automation, and advanced coordination modules

## Initial Outcome

This repository area is intentionally architecture- and planning-focused. It does not overbuild production systems yet. It prepares the teams, modules, and workflows needed to execute an MVP and scale responsibly.
