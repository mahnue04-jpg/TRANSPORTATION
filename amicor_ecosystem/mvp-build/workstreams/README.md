# MVP Workstreams

This folder contains operational workstream plans for the first Amicor Health ISF MVP execution cycle.

## Workstream Documents

- `workflow-planning.md`: end-to-end request to payout workflow and SLA baselines
- `dashboard-planning.md`: operations dashboard views, alerts, and controls
- `provider-flow.md`: provider journey from request intake to completion visibility
- `driver-flow.md`: driver lifecycle from assignment to payout-eligible completion
- `operational-execution.md`: staffing model, cadence, incidents, and governance

## How To Use

- Use each workstream as the source of truth for backlog creation.
- Keep acceptance criteria aligned with product tickets.
- Review weekly in operations-product planning.
