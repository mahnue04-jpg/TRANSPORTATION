# MVP Roadmap

This roadmap defines the minimum viable operational build for Amicor Health ISF.

## Phase 0: Foundation (Weeks 1-2)

- Confirm module boundaries and ownership
- Finalize workflows and role definitions
- Define API contracts and operational data model
- Prepare compliance and legal checklist

## Phase 1: Core Operations (Weeks 3-6)

- Authentication and role-based access controls
- Provider request creation and queueing
- Driver assignment workflows (manual + rules-assisted)
- Scheduling and ride state tracking
- Notification events for key status changes

## Phase 2: Financial and Oversight (Weeks 7-9)

- Payout tracking and reconciliation basics
- Admin dashboard for request and assignment visibility
- Baseline reporting (volume, completion, time-to-assignment)
- Exception workflow for cancellations and no-shows

## Phase 3: Launch Readiness (Weeks 10-12)

- Pilot partner onboarding
- Driver onboarding validation
- Operational runbook and escalation model
- Post-launch metrics and stabilization plan

## MVP Success Criteria

- Providers can create and monitor transportation requests
- Drivers can receive, accept, and complete assignments
- Operations team can track rides and payouts
- Core reports support partner confidence and grant reporting
