# Documentation Hub

This folder contains strategic and operational documentation for Amicor XS and Amicor Health ISF.

## Sections

- `foundation`: core business and operating model documents
- `operational-workflow`: execution flow for daily operations
- `partner-workflow`: provider and partner usage model
- `driver-workflow`: independent driver lifecycle and execution model
- `future-scaling-roadmap`: growth path for ecosystem expansion

## Documentation Standard

- Keep documents versioned and date-stamped in update sections
- Prioritize operational clarity over theoretical detail
- Link every workflow to owning module and decision owner
