# Operational Workflow

This document set defines how Amicor Health ISF operates day-to-day.

## End-to-End Flow

1. Provider submits transport request.
2. System validates request and checks service coverage.
3. Scheduler/dispatcher assigns vetted driver.
4. Driver confirms assignment and executes ride.
5. Ride status updates are sent to stakeholders.
6. Completion data is captured for payout and reporting.

## Operational Objectives

- Minimize assignment latency
- Ensure ride reliability for behavioral health appointments
- Capture auditable ride events
- Support quick exception handling
