# Driver Workflow

This workflow defines independent contractor driver operations in Health ISF.

## Driver Journey

1. Driver applies and is vetted.
2. Driver is onboarded and trained on standards.
3. Driver receives assignment opportunities.
4. Driver confirms, executes, and completes rides.
5. Driver payout is tracked and settled.

## Operational Expectations

- Timely acceptance and pickup behavior
- Accurate ride status updates
- Professional conduct and rider safety standards
- Reliable documentation for payout and compliance
