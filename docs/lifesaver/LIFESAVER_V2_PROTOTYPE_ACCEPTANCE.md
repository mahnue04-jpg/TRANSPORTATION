# Lifesaver V2 prototype acceptance

Use this after a Raspberry Pi is on a private LAN.

1. Install the Home Hub agent from `hardware/lifesaver-home-hub/`
2. Connect LAN (allowlisted private host only)
3. Discover and pair
4. Run self-test
5. Camera / mic / speaker simulations
6. STOP MOTOR, then limited rotation
7. Privacy on/off
8. Possible-fall review (no 911)
9. Disconnect / reconnect
10. Accept only if public IPs stay rejected and frozen products are untouched

Connected-health software acceptance (no hardware required):

11. Simulate a connected device, pair it, mark it offline, and reject an unsupported type
12. Advance a home-test kit one step at a time; expired kits stay locked
13. Store a result-document reference; confirm no diagnosis and no 911
14. Provider and Care Circle share fail without consent
15. Home Hub cards stay informational and labeled simulation

Physical parts remain NOT YET PURCHASED until recorded otherwise.
