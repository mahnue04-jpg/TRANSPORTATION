# Lifesaver Home Hub agent

Local prototype agent for a future Raspberry Pi Home Hub.

Version: `lifesaver-home-hub-agent 0.1.0-dev`  
This is application software, not flashed firmware.

## Safe assumptions

- Private LAN or loopback only
- No GPIO in this package
- No real camera stream
- No emergency-service calls
- No production secrets in the tree

See `docs/INSTALL.md` for the future Pi install sequence.
