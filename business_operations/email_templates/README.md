# AMICOR Email Templates

Ready-to-use email templates for AMICOR HEALTH ISF LLC (Minnesota).  
Tone: professional and welcoming.

**Do not use these templates to promise guaranteed income, specific pay rates, Medicaid eligibility outcomes, or HIPAA certification claims.**

## Placeholder Legend

| Placeholder | Description | Suggested default (replace before sending) |
|-------------|-------------|---------------------------------------------|
| `{{first_name}}` | Recipient’s first name | — |
| `{{organization_name}}` | Provider / partner organization name | — |
| `{{application_link}}` | Driver application URL | `https://YOUR_DOMAIN/platform-ops/driver-apply` |
| `{{provider_link}}` | Provider information page URL | `https://YOUR_DOMAIN/for-providers` |
| `{{meeting_link}}` | Scheduling / meeting URL | — |
| `{{amicor_email}}` | AMICOR contact email | — |
| `{{amicor_phone}}` | AMICOR contact phone | — |

Replace every `{{placeholder}}` before sending. Do not invent live phone numbers or email addresses in templates.

---

## Usage Notes

1. Copy the **Subject** and **Body** from the chosen template file.
2. Replace all placeholders with actual values for that recipient.
3. Keep messaging accurate: conditional approval is not final hire; discovery calls are informational.
4. Update `YOUR_DOMAIN` in link defaults when production URLs are confirmed.
