## Fastest Path to Critical Milestones

### 1) Fastest path to first pilot partner
1. Finalize and legal-review docs 01, 03, 04, 05, 06, 12.
2. Build partner-specific packet using docs 08, 09, 10, 11.
3. Run 10 targeted outreach meetings with segment-fit partners.
4. Move one partner to proposal, then contract signature.

Critical dependency: signed provider agreement plus clear pricing and SLA.

### 2) Fastest path to first recurring rider
1. Execute onboarding packet (doc 08) with signed partner.
2. Confirm authorized requestor list and recurring appointment roster.
3. Activate trained driver cohort and escalation contacts.
4. Run controlled recurring schedule for 1-2 weeks.

Critical dependency: recurring schedule commitment from partner coordinator.

### 3) Fastest path to first invoice
1. Lock billing terms from docs 01 and 12.
2. Use docs 04 and 05 to resolve cancellation/no-show edge cases.
3. Close first weekly billing cycle with reconciled ride records.
4. Issue first invoice to approved billing contact.

Critical dependency: clean, auditable completed rides and dispute-ready policy alignment.

### 4) Fastest path to first revenue
1. Send first invoice with confirmation of receipt.
2. Run AR follow-up cadence on agreed payment terms.
3. Resolve disputes within policy windows.
4. Collect first payment and archive evidence.

Critical dependency: finance owner executing collection workflow consistently.

### 5) Fastest path to first grant submission
1. Open grant pipeline and owner matrix with doc 13.
2. Build submission evidence repository using doc 14.
3. Populate budget workbook using doc 15.
4. Export KPI/reporting evidence from doc 16 framework.
5. Submit first complete packet with partner and pilot proof.

Critical dependency: evidence completeness, not narrative writing speed.

## Governance Recommendations
1. Create a weekly Business Readiness Council (COO, Partnerships, Grants, Finance, Ops, Legal).
2. Require owner, due date, and status for every missing information item in each document.
3. Track progress with a simple RAG status: Not Started, In Progress, Complete, Blocked.
4. Do not expand launch scope until first invoice and first payment are complete.
