How to set up a research memo

A research memo is a short document that answers one question with sources a reviewer can check. This guide is original AMICOR writing for the first-customer preview. It was editorially reviewed on October 11, 2026. It is not a paid placement.

Start with the question, not the tools

Write the decision the memo has to support, the date it is needed, and what would make it wrong. A useful memo names the question, the sources, the finding, and the limits. Collecting links without that question produces a pile, not a deliverable.

Keep three working files

Source log

One row per source: title, publisher, date accessed, URL or citation, and a one-sentence reason it matters. If a source is not in the log, it does not go in the memo.

Claim table

One row per claim: the sentence you might publish, the source that supports it, and whether the source is a primary document or a summary. Unsupported claims stay out.

Memo draft

Question, method, findings, limits, and the source list. Keep the draft separate from the log so notes do not get pasted in as conclusions.

How to choose software later

A citation manager is useful when the source list will be reused. A spreadsheet is enough for a single memo. Pick tools that export a source list you can hand to a reviewer. This prototype does not recommend a retailer and does not list product prices.
